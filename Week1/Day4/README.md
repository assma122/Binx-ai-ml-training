# Day 4 - Pandas



In this day, I learned how to work with tabular data using Pandas. I practiced loading, inspecting, selecting, filtering, cleaning, and grouping real datasets.

## Topics Covered

- Series and DataFrames
- Loading CSV files with `read_csv`
- Inspecting data using `head`, `shape`, `info`, and `describe`
- Selecting columns
- Filtering rows
- Using `loc` and `iloc`
- Handling missing values
- Removing duplicate rows
- Grouping and aggregation using `groupby` and `agg`


## Files

- `pandas_day4.ipynb`: Contains the lesson examples and hands-on lab.
- `file.csv`: Dataset used for practice.
- `train.csv`: Dataset used for the final lab.

## Tools Used

- Python
- Pandas
- Jupyter Notebook
- VS Code

## Summary

By the end of this day, I was able to load and inspect real datasets, clean missing and duplicate values, filter meaningful subsets, and calculate grouped statistics using Pandas.
