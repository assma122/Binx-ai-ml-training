# Milestone 3 — Supervised Baseline

- The task was defined as binary classification using `target`.
- The data was split into 80% training and 20% testing using stratification.
- Baseline model: Logistic Regression.
- Scaling was applied using StandardScaler.
- Baseline Accuracy: 0.869
- Baseline Precision: 0.812
- Baseline Recall: 0.929
- Baseline F1-score: 0.867
- Confusion matrix: TN=27, FP=6, FN=2, TP=26.
