# Outputs Folder

This folder contains the main saved results from the Cardiac Patient Monitoring System project.

## Folders

### figures/
Saved visual results from the notebook, including model evaluation plots, feature importance, tree-depth comparison, and final model comparison.

### tables/
CSV tables containing milestone-level results, cross-validation scores, tuning results, depth-analysis results, and final model metrics.

### summaries/
Short Markdown summaries for each completed milestone and the final project.

## Main Files Included

- Milestone 1 data-quality summary
- Milestone 2 descriptive statistics, target correlations, class balance, and outlier summary
- Milestone 3 baseline metrics and confusion matrix
- Milestone 4 model comparison, cross-validation scores, Random Forest confusion matrix, ROC-AUC, feature importance, tree-depth analysis, and hyperparameter tuning results
- Milestone 5 feature-engineering comparison
- Final model-results table including the Tuned Random Forest
- Cross-validation summary
- Random Forest tuning summary
- Random Forest depth-analysis results
- Short milestone summaries
