# Outputs Folder

This folder contains the main saved results from the Cardiac Patient Monitoring System project.

## folders

### figures/
Saved visual results from the notebook.

### tables/
CSV tables containing milestone-level and final numerical results.

### summaries/
Short Markdown summaries for each completed milestone and the final project.

## Main files included

- Milestone 1 data-quality summary
- Milestone 2 descriptive statistics, target correlations, class balance, and outlier summary
- Milestone 3 baseline metrics and confusion matrix
- Milestone 4 model comparison, cross-validation scores, confusion matrix, and ROC-AUC
- Milestone 5 feature-engineering comparison
- Final model-results table
- Short milestone summaries
