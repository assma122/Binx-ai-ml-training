## Featured Project — CineSense

### IMDb Sentiment Intelligence

CineSense is an end-to-end machine learning application that classifies English movie reviews as **Positive** or **Negative** and displays the model confidence.

### Live Demo

[Launch CineSense Live App](https://asma-movie-sentiment.streamlit.app/)

### Key Results

- **Accuracy:** 88.62%
- **Precision:** 87.76%
- **Recall:** 89.85%
- **F1-score:** 88.79%
- **Model:** Logistic Regression
- **Features:** TF-IDF with 5,000 features
- **Deployment:** Streamlit Community Cloud

### Project Workflow

IMDb Reviews  
→ Text Preprocessing  
→ TF-IDF Vectorization  
→ Logistic Regression  
→ Model Evaluation  
→ Streamlit Deployment
